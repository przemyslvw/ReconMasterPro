ReconMaster Pro

Automated reconnaissance plugin for Burp Suite Community Edition. Passively processes every HTTP response to build a full picture of the target's attack surface — no Pro license required.

passive recon bug bounty pentest offline

Modules

ModuleWhat it does
Endpoint Discovery Extracts and deduplicates URLs from JS, HTML and JSON responses. Groups by pattern (/api/users/{id}) and scores by exploit probability.
Tech Stack Fingerprinting Detects frameworks and library versions from headers, comments and CDN links. Cross-references an embedded offline CVE database.
Secrets Scanner Shannon entropy analysis + regex patterns for AWS keys, GitHub tokens, JWTs and more. Context-aware filtering ignores test fixtures.
CORS Hunter Tests all discovered endpoints for CORS misconfigurations (wildcard, null origin, credentialed requests). Generates ready-to-use PoC HTML.
GraphQL Extractor Auto-discovers GraphQL endpoints and runs introspection queries to map the schema.
Cloud Assets Aggregator Discovers S3, Azure Blob and GCS buckets from JS, HTML comments and CSP headers. Checks public exposure.
Attack Surface Timeline SQLite-backed timeline — alerts on newly appeared or disappeared endpoints within a configurable time window.
Report Generator One-click export to standalone HTML, JSON, Markdown or CSV (ZIP). Secret values are automatically redacted.

Requirements

  • Burp Suite Community or Professional Edition 2022.12+
  • Java 11 or later
  • No external API calls — everything runs offline

Performance

Tested at 1000+ endpoints: under 100 MB RAM, under 10% CPU overhead. All scanning runs on background threads — the UI never blocks.
