ReconMaster Pro is a powerful Burp Suite extension designed for automated target reconnaissance. It runs entirely offline to protect client confidentiality and satisfy strict BApp Store privacy policies.

Key Features:

  • Smart Endpoint Discovery: Automatically extracts and groups API endpoints (e.g., matching /api/users/{id}) using a highly optimized pattern clustering algorithm.
  • Technology Stack Fingerprinting: Fingerprints front-end and back-end framework versions offline, checking them against an embedded CVE database.
  • CORS Hunter: Passively audits and detects wildcard, null-origin, and credentialed CORS vulnerabilities.
  • GraphQL Schema Extractor: Automatically identifies GraphQL endpoints and visualizes database schemas.
  • Secrets & Credentials Scanner: Scans for API keys, AWS credentials, and tokens using Shannon entropy and strict pattern heuristics.
  • Subdomain & Cloud Assets Aggregator: Extracts and aggregates subdomains and cloud storage buckets (S3, Azure Blob, Google Cloud Storage) passively.
  • Attack Surface Timeline: Tracks changes in the target's attack surface over time using an embedded SQLite database.

Architecture & Performance:

Written utilizing the modern PortSwigger Montoya API and optimized for minimum footprint (typical memory usage < 100MB). All network requests, heavy regex matching, and database operations are processed asynchronously, ensuring the Burp UI remains responsive.
